# 01 - Controls and Compliance Checklist | Botium Toys

**Company:** Botium Toys (Fictional Retailer)
**Role:** Security Analyst (Audit)

### Summary
Audited Botium Toys scope document to check security controls and compliance (PCI DSS, GDPR, SOC).

### Key Findings
- Least Privilege & Separation of Duties not implemented - All employees have access to PII
- No Encryption, No IDS, No Disaster Recovery
- Physical controls (Locks, CCTV, Fire) are present
- GDPR notification plan exists but data is not secured

### Compliance Status
- PCI DSS: 4/4 Fail
- GDPR: 2 Fail, 2 Pass (as per latest scope doc)
- SOC Type 1 & 2: 2 Fail, 2 Pass
